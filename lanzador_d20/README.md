# Lanzador de Dados D20

## Estructura
- `/core`: Contiene el fondo animado base.
- `/entities`: Contiene los elementos del juego (el dado D20).
- `/ui`: Contiene los elementos de interfaz de usuario (Botones).
- `/assets`: Carpeta vacía lista para guardar imágenes y sonidos futuros.

## Cómo ejecutar
1. Abre tu terminal en esta carpeta (`lanzador_d20`).
2. Ejecuta `python main.py`.
